# Portfolio - Ethan Walker

A premium, brutalist editorial portfolio website designed and developed for **Ethan Walker** (Full Stack Web Developer & UI/UX Designer).

Built with **Vite, React, TypeScript, and Tailwind CSS**.

## Visual Design Details
- **Brutalist Editorial Grid Theme**: Features custom thick panel lines, structural outlines, high-end grids, and solid border layouts.
- **Satoshi & JetBrains Mono Fonts**: Loaded via Fontshare CDN.
- **Dynamic Mouse-tracking Cursor Spotlight**: Custom hover reveals on selected projects that show floating preview details.
- **Responsive & Dynamic Components**: FAQ accordions, endless horizontal marquee keyword ribbons, and interactive HTML5 Canvas visual systems.

## Local Development

To run the project locally, navigate to the folder and run:

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be served at `http://localhost:5173`.

## Deployment

### Vercel / Netlify (Recommended)
This project is configured as a standard React Vite application and is fully ready to deploy:
1. Push the contents of this folder to a GitHub repository.
2. Link the repository to **Vercel** or **Netlify**.
3. Use the default build settings:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click deploy and your site is live!
